# Marine Clinic Care

Build the Marine Clinic ERP UI in the current project.

Use React + TypeScript + Tailwind + shadcn/ui.

Create:

Login page

Responsive sidebar

Top header

Dashboard

Patient Records

Add Patient

Invoices

Payments

Staff Management

Reports

Activity Logs

Settings

Design: modern professional medical SaaS, white/light-gray background, navy/blue primary color, clean compact tables, minimal animations.

Create Admin and Staff roles with mock login.

Admin sees everything. Staff sees Dashboard, Patients, Invoices, Payments and Reports only.

Use mock data for now. No backend.
